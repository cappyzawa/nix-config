# Chore

引数でループ名を受け取り、この skill ディレクトリ内の `loops/<loop名>.md` の定義に従ってメンテナンスループを 1 周する。

## 実行手順

1. 引数のループ名に対応する `loops/<loop名>.md` を読む。引数なし・未知の名前の場合は `loops/` 配下の一覧と各ファイルの「目的」を提示して終了する
2. ループ定義の「発見」に従って queue を確認する。仕事がなければ「仕事なし」と報告して終了する
3. 1 件ずつ処理する。1 回の実行での件数上限はループ定義の「上限」に従う（省略時 3 件）
4. 各件の完了判定はループ定義の「検証」に従う。同一の件への修正リトライは 2 回まで。超えたらその件を中断し「要人間」として記録する
5. 処理結果をループ定義の「記録」に従って残す
6. 終了時に報告する: 処理した件数と内訳、作成した PR、残 queue、要人間の件

## ループ定義の書式

`loops/<loop名>.md` は以下の節を持つ:

- **目的**: 1 行
- **発見**: queue の場所と「未処理」の判定方法
- **実行**: 1 件の処理手順
- **検証**: 完了を証明する信号
- **記録**: 処理済みの残し方と成果物の出し方
- **上限**: 1 回の実行での件数上限（省略時 3）

## 原則

- 完了は検証で証明する。検証できない件は完了扱いにしない
- 破壊的操作（削除・force push・merge）はループ内で行わない。成果物は必ず人間がレビューできる形（draft PR 等）で出す
- queue の情報は消さない。処理済みは移動・注記で残す
